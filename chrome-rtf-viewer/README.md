### Info

Replica of [chrome-rtf-viewer](https://github.com/zoehneto/chrome-rtf-viewer) project. This extension allows one to view __RTF__ files in the browser. This plugin does not have other external depencies than [rtf.js](https://github.com/tbluemel/rtf.js) for rendering. The `rtf.js` and its dependecies are included in the 'external' folder for convenience.
